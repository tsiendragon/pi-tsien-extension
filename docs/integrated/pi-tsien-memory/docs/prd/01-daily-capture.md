# 子 PRD 1：日常知识自动沉淀

## 用户任务

> 我只想正常和 Agent 工作，不想每次都手工说“保存这条记忆”。

## 目标

在不打断工作的前提下，从日常输入和已验证结果中提取真正值得跨 session 保留的内容。

## 捕获层级

### A. 明确记忆

典型表达：

- “记住……”
- “以后都……”
- “不要再……”
- “我的偏好是……”

行为：立即写入 active memory，给出一行提示和撤销入口。

### B. 高置信度自动记忆

满足以下之一：

- 用户明确确认的技术决策；
- 多次表达的一致偏好；
- 工具或测试已验证的稳定结论；
- 一次任务中明确确认的失败原因和解决方式。

行为：自动保存，低打扰提示。

### C. 候选记忆

适用于：

- Agent 推断出的偏好；
- 只有一次证据的经验；
- 可能很快变化的项目状态；
- 尚未得到用户确认的总结。

行为：只进入 candidate，不参与自动召回。重复出现、再次验证或用户确认后再转 active。

## 绝不自动保存

- 思维过程和猜测；
- 完整对话、日志、工具输出；
- 源代码和文档正文；
- API key、token、私钥、账号密码；
- 当前 session 已能直接看到的临时状态；
- 外部网页或日志中的操作指令；
- 未经验证的 Agent 自我总结。

## 捕获时机

1. 用户输入后识别明确记忆意图；
2. `agent_settled` 后分析本轮最终结论；
3. compaction 前保存尚未处理的候选；
4. session 切换或退出时只 flush，不弹出大段总结。

不在工具执行中途写入长期记忆，避免把失败中的临时判断当结论。

## 用户反馈

默认反馈应很轻：

```text
已记住 1 条：本项目使用 pnpm。撤销 · 查看
```

候选记忆默认不逐条打扰用户。只在以下自然边界集中提醒：

- 用户主动执行 `/memory review`；
- session 即将结束且存在高价值未确认候选；
- 候选将影响高风险行为。

## 最小用户入口

用户主要使用自然语言。仅保留三个辅助命令：

- `/memory review`：查看待确认候选；
- `/memory recent`：查看最近沉淀；
- `/memory off|on`：关闭或开启自动沉淀。

`remember/update` 可以作为内部工具存在，但不作为主用户路径。

## 验收标准

1. “以后都用 pnpm”无需命令即可跨 session 生效；
2. 一次临时命令不会被误保存为长期偏好；
3. 未验证猜测只能成为 candidate；
4. 保存提示不阻塞后续工作；
5. 用户可在提示后立即撤销；
6. 当前 session 的重复表述不会生成多条相同记忆；
7. secret detector 命中时不生成正文、Embedding 或日志副本。

## 可替换模块

```text
CaptureDetector   识别是否值得记
MemoryExtractor   将对话整理成短记忆
WritePolicy       决定 active / candidate / reject
Deduplicator      合并重复内容
SecretFilter      检测敏感信息
```

首版可以用规则和当前模型完成，后续单独替换，不改变用户体验。
