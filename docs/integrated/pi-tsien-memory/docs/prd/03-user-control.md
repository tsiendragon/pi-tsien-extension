# 子 PRD 3：查看、纠正与遗忘

## 用户任务

> Agent 记错时，我要一句话就能纠正；不想保留时，也要真正停止使用。

## 目标

让用户通过自然语言控制记忆，不需要理解 ID、revision、索引或数据库。

## 核心交互

### 查看

用户可以问：

- “你记得我什么？”
- “这个项目你记住了哪些约定？”
- “刚才保存了什么？”
- “你为什么认为要用 pnpm？”

结果按主题展示短摘要、scope、来源和最近使用时间。ID 只作为高级信息。

### 纠正

用户说：

> Node 20 那条过时了，现在统一用 Node 22。

系统应：

1. 自动定位候选记忆；
2. 唯一命中时直接展示修改摘要；
3. 多个命中时让用户选择；
4. 保留“旧值被新值替代”的历史关系；
5. 更新搜索索引；
6. 提供撤销。

### 遗忘

用户说：

> 忘掉刚才的测试账号。

系统应：

1. 先定位目标；
2. 敏感或不可逆删除前确认；
3. 从正常搜索和注入中立即移除；
4. 删除关联的搜索索引、Embedding 和缓存；
5. 只保留不含正文的删除回执；
6. 验证该内容无法再次召回。

## 必要命令

自然语言是主入口。命令只用于精确控制：

- `/memory show [query]`
- `/memory review`
- `/memory recalled`
- `/memory forget [query]`
- `/memory settings`

不要求用户使用 `/memory update <id>`。

## 设置

只暴露用户能理解的开关：

- 自动沉淀：开 / 关；
- 自动召回：开 / 关；
- 默认范围：仅当前项目 / 允许全局偏好；
- 远程处理：默认关；
- 保留候选时间；
- 一键导出和清空。

不在普通设置中暴露搜索权重和数据库参数。

## 隐私体验

- 默认本地；
- 首次启用远程模型时说明会发送什么；
- 对 `.env`、token、密码和私钥默认拒绝保存；
- 用户可以查看某条记忆的完整来源链；
- 删除 scope 时支持“只删当前项目”或“全局删除”；
- 项目被移除时提醒是否同步清理项目记忆。

## 验收标准

1. 用户不提供 ID 也能纠正唯一匹配的记忆；
2. 多个相似目标不会被误删；
3. 遗忘后普通搜索、自动召回和缓存均无结果；
4. 用户能回答“为什么 Agent 知道这件事”；
5. 用户可撤销最近一次写入或更新；
6. 全局清空属于破坏性操作，必须明确确认；
7. 默认界面不暴露实现细节。
