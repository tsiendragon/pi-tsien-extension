# pi-tsien-extension v0.1.0

首个公开发布（2026-09-27）：**26 个 Pi 扩展包**，MIT 许可。其中 25 个可直接加载，`pi-tsien-shared` 为共享库。

## 安装

一次装齐全部扩展（推荐，功能完整）：

```bash
pi install git:github.com/tsiendragon/pi-tsien-extension
```

按需安装单个包（npm，首发 10/26，见下表最后一列）：

```bash
pi install npm:pi-tsien-goal
```

环境要求：**Node.js >= 22**，以及 [Pi Coding Agent](https://github.com/earendil-works/pi-mono)。
使用补丁 API 的扩展需要补丁版 pi（`>=0.84.2 <1.0.0 || ^0.85.1-tsien.1`）。不知道哪些需要？dashboard 的 Extensions 页会把它们标成「需补丁版 pi」。

## 质量与兼容

- 拆包前后做了**等价性验收**：`npm run parity:check` 25/25 条目与迁移前指纹逐条一致（工具、命令、事件、调用签名）。
- 每个包都有独立 `package.json`、README、LICENSE，并声明 `license` / `repository` / `files`。
- 已知限制：
  - npm 首发只到 10/26（npm 账号级发布限流），其余 16 个请用上面的 GitHub 伞形包安装，功能完整、无差别；
  - 少数包是第三方 fork（`pi-tsien-rtk-fork`、`pi-tsien-session-ui-fork` 等），原始出处与许可记录在包内 README/`ATTRIBUTION.md`，遵循其原始许可；
  - 依赖 dashboard 桥接的能力（配置写入、live session 页面操作）需要浏览器认证。
